# Paleozone files anchor interpolation through the 5° conceptual lattice

The October point files dropped the conceptual grid, and every published raster changed even at ages whose data points barely moved. Power, radius, KNN and edge smooth were the same. The grid is not the paleozone layer and it is not drawn. It is the set of 5° nodes, in the source frame, that fall inside a paleozone polygon. The node's class is that polygon's class. Where a node sits in both a dry polygon and a semi-arid polygon, the previous grid kept Dry, which is `CLASS_TIE_PRIORITY`. Sampling `{age}_ma_paleozones.geojson` that way reproduces the old anchors at every age that has the file. The polygons are still not drawn and are not painted into the raster. 115 Ma has conceptual anchors and no paleozone file, so those 206 nodes stay in `conceptual/115_ma.geojson`. 145 Ma has neither, and stays data points only.

**Considered options:** (1) sample the paleozone files onto the 5° lattice and keep the layer off; (2) paste the old conceptual rows back into `{age}_ma.geojson`; (3) leave the October files as the only anchors. (3) is what made every zone redraw. (2) mixes the October table with the previous generation of the point file. (1) is the run. Supersedes the "grid stays dropped" choice in `docs/adr/0027-october-points-replace-the-viewer-points.md` and the "paleozones do not constrain interpolation" line in `docs/adr/0001-paleozones-do-not-constrain-interpolation.md` and `docs/adr/0020-paleozones-are-not-drawn.md`. The polygons still do not mask or hard-fill a cell.

**Consequences:** For every age that has `conceptual/{age}_ma_conceptual.geojson`, that file is the lattice and this sample is only the fallback. See `docs/adr/0041-conceptual-files-anchor-interpolation.md`.
