# The viewer changes age only through the age menu

The younger and older buttons stepped one reconstruction age at a time, and the left and right arrow keys did the same from anywhere on the page. Both are gone. The age menu is the only control that changes the map. Arrow up and arrow down still move through ages while that menu's button is focused, because that is the menu itself.

**Considered options:** (1) remove the buttons and the page-level arrow keys, and keep arrows inside the age menu; (2) remove the buttons and keep the left and right arrow keys; (3) remove every keyboard path, including arrows on the menu. (2) leaves a second way to change age. (3) makes the menu harder to use from the keyboard.
