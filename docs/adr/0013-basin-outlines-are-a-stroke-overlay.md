# Basin outlines are a stroke overlay

A basin outline is the sedimentary-basin limit at one reconstruction age. It is not the basin filter on data points, and it is not a Paleozone. Each age that has `{base}_basins.geojson` gets one Layers checkbox, **Basins**, drawing every polygon in that file as a stroke. The checkbox starts off. Hover shows `BASIN_NAME` and nothing else. The filter still only hides markers. The outlines do not seed or mask the raster. They take the same paleo-frame rotation as points, coastlines, and paleozones, because the files are still in the Zahirovic OptimisedMantleRef frame (Barreirinhas at 100 Ma sits near 15°S, and the published maps put northern Brazil on the equator). An age with no file, including 145 Ma, simply has no checkbox. The PDF follows the checkbox: the pre-rendered PDF is the default state, so it has no outlines until someone turns the layer on and exports from the browser. Geometry is embedded vertex for vertex. Properties other than `BASIN_NAME` are dropped, so exploration status and source URLs are not published inside the map. The stroke sits above the coastline and below the markers, in a wine colour (`#6b2d4a`) that is not the slate shoreline or a climate class.

**Considered options:** (1) this overlay; (2) a filled belt in the Paleozone style; (3) one checkbox per basin, or outlines that follow the point filter; (4) skip the extra rotation because the files are already plate-rotated; (5) start the layer on; (6) simplify the ~106k vertices; (7) draw only South American basins. (1) matches the request: one toggle, contour only, all 88 polygons, limits you can turn on without changing the climate reading.
