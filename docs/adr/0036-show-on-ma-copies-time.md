# Show_on_Ma is copied from TIME and is not on the form

Show_on_Ma stays a column in the downloaded GeoJSON, and it is not a field the author fills in. Each added point gets Show_on_Ma equal to that point's TIME, as an integer age in Ma.

**Considered options:** (1) hide the field and copy TIME; (2) keep a second age menu; (3) omit Show_on_Ma from the file. (2) asks for the same age twice. (3) drops a column the October table has.
