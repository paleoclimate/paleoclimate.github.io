# The first section is the required fields

The add-points form opens with a Required heading and the sentence "All fields in this section are required." Those fields are Latitude, Longitude, TIME, Climate_Cl, Country, Basin_Sub_, Formation, PlateID, and REF(Authors, Year). Latitude and longitude use a dot in the placeholder (`-12.34`, `-45.67`). Group, Member, and Well name/outcrop are not required; they sit under Optional Fields with the other October notes. Optional Fields is the larger heading, with a rule under it. Empty optional text is still null.

**Considered options:** (1) require every field that stays in the first section, and move Group, Member, and Well name/outcrop under Optional Fields; (2) leave Country, basin, formation, PlateID, and the reference optional under a heading that says the section is required. (2) would label optional columns as required.
