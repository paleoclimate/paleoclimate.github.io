# A point popup shows the reference, and more behind a plus

Clicking a data point already named the formation, basin, country, climate and age. The same popup now always shows the citation in `REF(Authors, Year)`, labeled Reference. Paleoenvironment (`Paleoenvironment`), Dating Evidence (`Dating evidence`) and Lithology (`Lithology, structures, paleowind`) stay behind a plus, as a disclosure on that point. A location with several points gives each one its own plus. Empty cells read N/A. The spaced column `REF (Authors, Year)` is a different citation and is not the line in the popup.

**Considered options:** (1) reference always visible, the three notes behind a plus; (2) all four fields always open; (3) use the spaced reference column instead. (2) makes every popup a long lithology note. (3) would show the other citation, not the column that was named.
