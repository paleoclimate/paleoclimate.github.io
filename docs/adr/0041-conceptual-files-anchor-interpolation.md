# Conceptual files are the interpolator anchors

Seventeen conceptual lattices, one per reconstruction age from 65 Ma through 145 Ma, replace the single recovered grid at `conceptual/115_ma.geojson`. Each file is `conceptual/{age}_ma_conceptual.geojson`. When that file has conceptual points, those points anchor KNN/IDW and the paleozone polygons are not sampled. Sampling `{age}_ma_paleozones.geojson` onto the 5° lattice remains only for an age that has no conceptual file. The points are still not drawn. Sixteen files store the class in `Climate_Cl`. The 145 Ma file stores it in `Paleozona` (`humid`, `dry`, `semi-arid`) and has no `Climate_Cl`; the loader copies that label onto `Climate_Cl` with the same map the paleozone polygons already use, and a point with neither field is left out. That keeps 145 Ma from entering the raster as an all-semi-arid grid. The new anchors change every published raster, including 105 Ma and 115 Ma, so the Floegel and Hay comparisons are rescored from those rasters.

**Considered options:** (1) prefer the conceptual file and fall back to the paleozone sample; (2) use the file only when the age has no paleozone file, which is what `conceptual/115_ma.geojson` did; (3) merge the file with the paleozone sample; (4) drop the 145 Ma file because it has no `Climate_Cl`. (2) would leave fifteen of the seventeen files unused and would not change the rasters or the comparison. (3) would put two anchors on one node. (4) would leave 145 Ma as data points only and ignore the file supplied for that age. (1) is the run, with the Paleozona label read for 145 Ma.

**Consequences:** Supersedes the paleozone-sample source in `docs/adr/0039-paleozone-lattice-anchors-interpolation.md` for every age that has `conceptual/{age}_ma_conceptual.geojson`. The "no conceptual points" line in `docs/adr/0006-keep-145-ma-in-this-candidate.md` is out of date; 145 Ma still stays in the generation.
