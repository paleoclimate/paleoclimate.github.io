# Paleoclimate atlas

The published maps of reconstructed climate, and the screen where an author queues new points for the local point files.

## Language

**Reconstruction age**:
One map in the atlas, named in millions of years.
_Avoid_: year, time slice

**Age menu**:
The control that opens one reconstruction age.
_Avoid_: age slider, age stepper, younger button, older button, volume bar, timeline

**Added point**:
A point queued on the add-points screen until the author downloads the collection.
_Avoid_: upload, draft row

**Show_on_Ma**:
The reconstruction age a point is drawn on. For an added point it is the same age as TIME.
